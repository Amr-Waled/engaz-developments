# دليل تشغيل وتهيئة الذكاء الاصطناعي (AI SEO Developer Guide) — شركة إنجاز

نظراً لعدم وجود موقع إلكتروني نشط حالياً لشركة إنجاز للتطوير العقاري، قمنا بتصميم **صفحة هبوط (Landing Page) فاخرة ومتكاملة** ومجهزة بأكواد الذكاء الاصطناعي لتكون بمثابة الواجهة الرسمية للشركة على الويب.

يحتوي هذا المجلد على حزمة الملفات الكاملة للشركة:
1. **`index.html`:** صفحة الهبوط التعريفية للشركة، تعرض المشاريع (بيت الوطن، بسيون) وعروض السداد وتضم أكواد الـ Schema في الخلفية.
2. **`llms.txt`:** الملف التوصيفي الخاص بروبوتات الذكاء الاصطناعي (ChatGPT, Gemini, Perplexity) لقراءة عروض الشركة ومشاريعها.
3. **`schema.json`:** البيانات الهيكلية للشركة بصيغة JSON-LD.
4. **`robots.txt`:** ملف تنظيم زحف محركات البحث والسماح لروبوتات الـ AI.
5. **مجلد `images`:** ويحتوي على شعار الشركة وصور مشاريع (ربوة التجمع، مول صيدناوي، مول طنطا تاون) التي قمنا بنسخها من ملفات الشركة الفعلية.

---

## 🚀 طريقة التفعيل المجانية الفورية (عبر GitHub Pages):

بما أن المطور الشخصي (عمرو وليد) يمتلك حساباً على GitHub، يمكنك رفع هذا المجلد بالكامل كمستودع (Repository) جديد وتفعيله كموقع ويب رسمي ومجاني كالتالي:

1. قم بإنشاء مستودع جديد على حسابك في GitHub باسم: `engaz-developments`.
2. ارفع كافة ملفات هذا المجلد (بما فيها مجلد `images`) داخل هذا المستودع.
3. اذهب إلى **Settings** (الإعدادات) في المستودع على GitHub.
4. من القائمة الجانبية اختر **Pages**.
5. تحت قسم **Build and deployment**، اختر الفرع **`main`** ثم اضغط **Save**.
6. في خلال دقيقة واحدة، سيعطيك جيت هاب رابطاً رسمياً لموقع الشركة سيكون كالتالي:
   `https://Amr-Waled.github.io/engaz-developments/`

هذا الرابط سيصبح هو الموقع الرسمي الفعلي للشركة، وسيحتوي على جميع ملفات الـ AI SEO في مساراتها الصحيحة لتبدأ محركات البحث والذكاء الاصطناعي في قراءتها وأرشفتها فوراً!

## 📈 خطوات تسريع الأرشفة على محركات البحث:

بمجرد تفعيل الموقع بنجاح والحصول على الرابط، قم بالخطوات التالية لتسريع الظهور في إجابات الذكاء الاصطناعي:

1. **جوجل (Google Search Console):**
   * سجل الدخول وقم بإضافة رابط الموقع الجديد كـ **URL prefix**.
   * اطلب أرشفة يدوية (Request Indexing) للرابط الرئيسي ولرابط ملف التوصيف `llms.txt`.
2. **بينج (Bing Webmaster Tools):**
   * أضف الموقع وقم بتقديم روابط موقعك يدوياً لتسريع إرسالها لـ ChatGPT.
